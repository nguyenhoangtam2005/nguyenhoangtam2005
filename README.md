## 🧠 Design Approach

I value **clarity over complexity, usability over decoration, and meaningful product outcomes over visual polish.**

My design process focuses on understanding the problem before designing the solution:

**Discover → Define → Structure → Design → Test → Refine**

I continuously question:

- Why does this feature exist?
- What problem does it solve?
- How will users interact with it?
- Can the experience be simpler?
- Is the solution practical to implement?
